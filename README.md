# TPGlobo — Frontend

Frontend do projeto TPGlobo, desenvolvido para gerenciamento e apresentação de roteiros em um teleprompter.

## Tecnologias

- HTML
- CSS
- JavaScript

## Situação atual

Projeto em desenvolvimento.

Nesta primeira etapa, será implementado o CRUD de roteiros, usando armazenamento local para simular a persistência dos dados.

A integração com o backend será realizada depois.
