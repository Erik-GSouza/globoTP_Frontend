# TPGlobo — Frontend

Frontend do projeto acadêmico **TPGlobo**, um sistema de teleprompter inteligente voltado à criação, gerenciamento e apresentação de roteiros.

## Sobre o projeto

Tem como objetivo facilitar a apresentação de roteiros por meio de uma interface de leitura e reconhecimento de voz para acompanhar a fala do apresentador e controlar a rolagem do texto.

## Tecnologias

- HTML5
- CSS3
- JavaScript (previsto)

## Estado atual

**Versão inicial — Interface visual**

Esta entrega contém o layout estático da página de gerenciamento de roteiros, desenvolvido com HTML e CSS.

Funcionalidades presentes:
- Estrutura visual da lista de roteiros.
- Área de visualização do título e conteúdo.
- Interface em tema escuro, inspirada no protótipo do Figma.
- Layout responsivo para diferentes tamanhos de tela.

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
